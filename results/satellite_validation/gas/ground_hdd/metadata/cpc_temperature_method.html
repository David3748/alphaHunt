Notes: All monthly temperature analyses are based on 344 Climate Divisions (CD). The temperature analysis for the current month is based on preliminary daily values valid for the CD based on a regression from scarce station data within each CD, station data that is selected because it is the best available in near real time. The procedure was developed by Heddinghaus (CPC) and is used in several other near real time CPC products, such as Palmer Index, heating degree days etc etc ".
Anomaly: from 1991-2020 Climatology (unit: oC)
